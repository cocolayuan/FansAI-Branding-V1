# FansAI Branding Data · 设计规范 V2

更新：2026-11-16。总结当前已确认的移动端设计与偏好，并对应实际组件。后续设计草稿继续先在本地确认；本次更新由用户明确授权同步，不代表未来自动发布。

## 视觉方向

以 Apple Health / Watch 的组件化读数、局部交互和信息层级为参考，保持国际化、舒展、精确的表达。黑色页面与深灰青卡面承载内容，薄荷和冰蓝作为数据主色；琥珀、钴蓝及斜纹承担需要区分的状态。适量有色玻璃和柔和内光，不堆叠霓虹、外发光、透明层与装饰线。

数字是主角：轻字重、大字号、清楚单位、等宽数字；密集客户与项目列表维持深色。白色小分析模块用较轻标题和数字，依靠面与留白建立层级。不同模块可以有形式变化，但字体、圆角、间距、操作方式要属于同一体系。

## Chart 的核心决策

| 数据问题 | 已采用的表达 | 语义约束 |
| --- | --- | --- |
| 有多少 | 小型单位点阵、短划线、等高计数柱＋数字 | 每个标记代表记录数；超容量明确倍率与末格余数 |
| 已收与待收各占多少 | 并排比例块、薄荷实色与冰蓝斜纹 | 宽度按金额占比分配，分母为已收＋待收 |
| 合同金额是否集中 | 100 点占比矩阵＋精确金额/分组详情 | 每点约1%；舍入图形不能替代精确读数 |
| 在制项目分布 | 阶段比例块＋图例 | 实际阶段数量决定宽度，合计必须与在制数一致 |
| 建联至回款如何转化 | 共同比例尺的阶段柱＋前一步转化率 | 保留阶段身份色，零分母不伪造百分比 |
| 谁贡献更多 | 排序横条＋精确金额 | 本组最大值用于比较；不是目标完成率 |
| 历史如何变化 | 真实日期曲线＋触摸/键盘读数 | 缺失处断开，不用随机高度或虚构历史 |
| 是否回本 | Growth 主 ROI 仪表盘及历史曲线 | 100% 是回本线；作为重点组件保留，不复制到所有卡 |

三个容易混淆的点阵要明确区分：**KPI 点阵是计数单位，集中度点阵是金额占比，Growth 收入波纹是装饰**。装饰不宣称数据单位，必须与准确文字读数分开。

当前 Global 六张 KPI 为：客户数（薄荷点阵）、新增客户（冰蓝短划线）、已签约客户（计数柱）、在制项目（阶段比例块）、本周交付（细杆端点）、已延期（琥珀斜纹柱）。112、66、4 与 25、2、6 是演示数据结果，不是写死的设计常量。

缺失用 `—`，真实零用 `0`。不混合周期、币种、统计快照，也不以假的目标包装比较条。对精确数值、分母、倍率和来源的解释，应比视觉效果更可靠。

## 交互与动效

点击比例块或分组，数字、金额和明细同步响应；历史曲线可触摸、键盘定位日期。多状态图表用颜色＋纹理＋标签共同区分，选中时保留身份色，用亮度、轻抬升和文字体现选择。

Customers 数字入场约380ms、计数标记约500ms、比例块约950ms；动画有终点，不持续随机变化。离屏/隐藏暂停、卸载清理，`prefers-reduced-motion` 显示最终结果。静态图形必须完整可读。具体组件规则见 [Chart 详规](../skills/fansai-branding-data-v2/references/charts.md)。

## 页面与组件一致性

- 四主标题：`Growth`、`Customer`、`Decisions`、`Workbench`，统一青色主字、白色方句点及原始云朵。云朵等比显示，长标题适配可用空间。
- 四 Tab 真实加载态：统一黑底、深灰青圆角骨架及加载时的深色玻璃导航；缓存内容就绪时立即显示。
- 工作台：客户业务与产品增长图标/文字分开，内部项目和知识库保留整卡；图标画布统一圆角，知识库与供应商同尺寸；分组留白增大，`Shared Space` 英文大标题下移除解释小字。
- 图标：用户指定 Figma 原资源、同名匹配；没有同名资源先说明。未开放入口隐藏；明确保留的内部项目以右上小标签标示开发中。
- 浮层：统一 Growth 浅灰蓝底部 Sheet、白色内容面、浅蓝选中、右上中性取消/关闭。深底薄荷按钮用于真正的应用/保存动作；只读详情不放深色主按钮“关闭”。

精确令牌、资源节点与几何见 [视觉规范](../skills/fansai-branding-data-v2/references/visual-system.md)；各类浮层的结构和行为见 [Sheet 规范](../skills/fansai-branding-data-v2/references/mobile-overlays.md)。

## 不再采用

- 无法解释回款含义的乐器状波浪管、所有指标套同一仪表盘。
- 单个累计数虚构趋势、无来源目标进度、为了好看修改原始数据。
- 白色密集列表、横穿白卡的深色明细条、装饰性细分隔线。
- 多种状态用近似色而无标签/纹理；透视和动画改变真实比例。
- 每层发光、无限跳动、为播放动画人为延迟已经就绪的页面。
- 移动端混用旧白底弹窗、桌面居中模态和孤立右下角深色关闭按钮。
