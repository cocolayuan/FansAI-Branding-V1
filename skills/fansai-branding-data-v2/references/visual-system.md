# 视觉与组件

## 方向与层级

国际化、舒展、精确；以 Apple 组件的读数层级和触达方式为参考。黑底上的有色玻璃与柔和内光是局部材质，不是每一层都透明、描边和发光。背景保持安静，让数据与可操作元素成为焦点。

当前手机画幅默认左右约 16px。复用已有容器，不把桌面 36px 边距或居中模态直接搬进手机。每次仅处理用户指定的页面；例如统一四个主标题不意味着重做决策列表。

| 角色 | 当前基准 |
| --- | --- |
| 主画布 | `#000000` |
| 工作台分组面 | `#0A161B` |
| 深色数据卡 | 深灰青，KPI 常用 `#1B323C → #152730` |
| 主标题 | `#4BEAFF` |
| 薄荷数据 | `#8FEEDA`，亮部可用 `#B9FFEC` |
| 冰蓝数据 | `#97C9F1` / `#A4D3F4` |

| 琥珀 | `#F2BB76`；延期时表达真实风险，阶段图也可作明确标注的分类色 |
| 主文字 | `#E5EFF3` / `#DCE8ED` |
| 辅助文字 | `#8EA5AF`，按背景保证可读 |
| 加载骨架 | `#10191F`，黑底、无额外描边 |

这些是当前组件的角色令牌，不要求把所有图形改成同一个色值。颜色应帮助读出分类、状态或重点。

## 字体与数字

- 沿用项目的 Geist 与系统中文回退字体。数字开启 tabular-nums，完整值用于可访问标签；紧凑显示不丢失精确值。
- 四个主标题共用 43px / 700 基准、青色文字及白色尾标。长标题按实际剩余宽度适配，不裁切，不挤压头像或日期筛选。实际字宽和字体加载完成后都要复核。
- 白色小分析模块及 Global KPI 不使用全粗体：标签约 450，数值约 450；强弱通过尺寸、留白和颜色建立。KPI 数值常规 36px，窄屏 32px。
- Workbench 分组标题为 650（由旧 500 增加 30%）、常规 15px；大区标题 `Shared Space` 为 26px / 650。名称下方不再堆解释性小字。
- 金额前缀、百分号和单位比主数值小，基线协调；长金额不能被挤出卡片或用无解释的截断代替。

## 卡片与圆角

- Workbench 分组卡圆角 24px、组间距 28px，窄屏组卡可用 22px。分组头和图标之间留足空间。
- 同一类图标的黑色画布统一 16px 圆角，圆角作用于画布，图像 `object-fit: contain`，不为了铺满裁掉原图。
- 内部项目和知识库使用 18px 整卡圆角；知识库与供应商共用同样的两列槽位、黑底卡片尺寸和 88×88 图标舞台。不要因为只有一个知识库入口就缩成四列小格。
- 客户业务、产品增长：黑色方形图标画布在上，文字在画布外，仍是一个完整点击目标。内部项目：图标和文字留在同一张黑卡。
- 用空间和背景面区分模块；不要增加无意义的竖分隔线、发丝描边或横穿白色分析卡的深色明细条。选择详情作为完整内嵌卡呈现。

下载 Figma 返回的原资源并存进工程，保留节点及文件校验信息，运行时不依赖会过期的资产 URL。没有同名资源时先报告缺项，不擅自借用看起来相似但语义不同的图。

Demo 可用已获准的 Unsplash 人像填充人员列表，注明是示例并保留来源；真实员工身份不由陌生照片代替。这个约定不授予为所有真实账号更换头像的权限。

## 导航、列表与动效

- Customer 子切换沿用 Growth 的圆角、背景和高度体系，避免方正的独立新控件。客户资料默认定位“立项”；客户及项目数据列表保持深色。
- 未开放的下方工作台入口隐藏，同时隐藏空分组。当前明确保留的内部项目预览，在卡片右上角放小“开发中”标记，不能让它看起来已可使用。
- 复用已有底部玻璃导航和 Rive 反馈。图标入场或卡片展开服务于方向感；有限动画约 180–500ms，按压轻缩放，不连续弹跳或旋转图标。
- 四主 Tab 的真实 pending 共用同一骨架。加载时临时采用深色玻璃导航，保持可点；完成后恢复用户外观偏好。工作台同步就绪时直接显示，不制造假等待。
- 保留 `prefers-reduced-motion`、隐藏页暂停和卸载清理。标题、状态标签、数据和按钮必须在没有动画时仍清楚。
